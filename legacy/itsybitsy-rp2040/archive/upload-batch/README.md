# Upload-batch archive

Files preserved from the same dump as the ItsyBitsy RP2040 legacy sketches. They are not part of the RP2040 LED controller runtime.

| File | What it is |
|---|---|
| `adafruit-circuitpython-feather_m0_express-en_US-7.3.3.uf2` | CircuitPython image for Feather M0 Express (SAMD21), not RP2040 |
| `update-bootloader-feather_m0_express-v3.14.0.uf2` | Bootloader update for Feather M0 Express |
| `pi-hole-raspberrypi-teleporter_2025-01-21_16-28-08.tar.gz` | Pi-hole teleporter export; unrelated to LED firmware |

For RP2040 flashing, use `../bootloader/` and the sketches under `../sketches/`.
